# NeedleBub prototype context
<!-- impeccable:product-schema 1 -->

This is an isolated, provisional design-study workspace, not production authority.

## Platform
web

## Product Purpose
NeedleBub provides phone-local tools, currently one-time-code extraction from selected Android notification sources. The UI is React in a Capacitor Android shell. Setup requires the model pack, notification access, permission for result notifications, and selected sources.

## Brand Commitments
User wants the interface to carry the manga, cyberpunk, robot and emoticon character of their current LilBub/NeedleBub vector art. Preserve the user's authored cat-and-needle mark. Explore personality in structure and states, not simply a logo placed on generic cards.

## Capabilities and Constraints
No cloud-inference claims; no real notifications or private data in these studies. Do not alter the production frontend, Android code, approved artwork, or shared design skills. All results and sample states are illustrative. No new launcher icon has been approved. README.md lines 78-106 state that normal operation never persists extracted codes or notification bodies and has no normal-user result history. Preserve that privacy boundary in prototypes.

## Open decisions
Home-screen long-term focus (recent results versus multi-tool management) is not confirmed. For comparable prototypes, use a ready one-time-code tool with illustrative content-free activity and visible source access. Two studies have been proposed and the user said Start: pocket robot control panel and manga-styled cyberdeck.
