# NeedleBub Design A assets

Selected for the slimmer A app UI on 2026-09-24. These SVGs are exact copies of the Open expression assets authored in Pawth, with preserved named editable groups.

Expressions have separate 96 × 48 and 32 × 32 optical sizes. Use them on the charcoal display or compact charcoal tile, with a visible state label. Functional glyphs use a 24-unit grid; render at 20–24 px inside 48 px touch targets. Use CSS masks with currentColor for controls across light/dark themes.

The authored cat-and-needle product mark remains /needlebub-mark.svg. These expressions are in-app status artwork, not launcher replacements.

Editable source board and the finalized review page are in artifacts/design-studies-2026-09-22/asset-studies. manifest.json records the shipped SVG hashes.
